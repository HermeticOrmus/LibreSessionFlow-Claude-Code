# Beginner — your first handoff + pickup cycle

## Mindset shifts

1. **Sessions end.** Treat them as a finite resource. Context clears. Plan for it.
2. **Future-you is a stranger.** Write for them, not for status-report aesthetics.
3. **Verify-still-done is mandatory.** State drifts between sessions; what was done may not be done.
4. **One next step.** Not three. One. The next session knows what to start.

## Walk

1. Work on something for 30+ minutes with state to preserve
2. Run `/handoff` — answer the gap question honestly
3. Read the draft; add what's missing; save
4. End the session (clear, exit, sleep, switch machines)
5. Come back — run `/pickup`
6. Read what comes back; verify; continue

Do this 3-5 times. The habit becomes invisible.

## Common newcomer mistakes

- Writing a status report instead of a handoff
- Skipping verify commands ("I'll remember")
- Vague "next step" — "continue the work"
- Treating HANDOFF.md as a journal — it's a baton pass
