# Close

> End-of-session ritual. The full wrap-up: write handoff, update memory, notify next-self, exit cleanly.

## What it orchestrates

- `/handoff` to write HANDOFF.md
- `/absorb` to update persistent memory with session learnings
- Notification to next-self via WhatsApp / Slack / email (configurable)
- Optional: commit + push if the session had a clear shipping outcome
- Final session summary printed before exit
